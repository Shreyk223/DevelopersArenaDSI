# 🚀 AI-Driven Customer Churn Prediction & Business Intelligence System

## 📌 Project Overview

This project presents a complete end-to-end **Business Intelligence and Machine Learning solution** focused on solving one of the most critical challenges faced by telecom and subscription-based businesses: **Customer Churn Reduction and Revenue Optimization**.

Using advanced **Customer Segmentation**, **Clustering Algorithms**, and **Predictive Machine Learning Models**, the project identifies high-risk customers, analyzes behavioral patterns, and generates actionable retention strategies to improve customer lifetime value (CLTV).

The workflow integrates:

* Data preprocessing & feature engineering
* Exploratory Data Analysis (EDA)
* Customer segmentation using clustering
* Churn prediction using supervised learning
* Business strategy recommendations
* Executive-level reporting & visualization

The final outcome is a deployable AI-driven business intelligence framework capable of supporting data-driven decision-making.

# 📊 Dataset Description

The dataset contains customer demographic, subscription, and billing information, including:

| Feature          | Description                    |
| ---------------- | ------------------------------ |
| Tenure           | Customer subscription duration |
| MonthlyCharges   | Monthly subscription amount    |
| TotalCharges     | Overall customer spending      |
| Contract         | Contract type                  |
| PaymentMethod    | Payment mode                   |
| PaperlessBilling | Billing preference             |
| InternetService  | Service category               |
| Churn            | Customer retention status      |

The project processes and analyzes more than **500 customer records** for segmentation and churn prediction.

# 🤖 Churn Prediction System

Random Forest and Decision Tree models were trained to predict customer churn probabilities.

## Model Performance Highlights

* High predictive accuracy achieved
* Strong ROC-AUC performance
* Improved classification after hyperparameter tuning
* Feature importance analysis performed

## Key Churn Indicators

* High monthly charges
* Short tenure
* Month-to-month contracts
* Premium onboarding instability

---

# 📈 Major Business Insights

## ✅ Key Findings

* Customers with high monthly charges show significantly higher churn risk.
* Long-term customers demonstrate stronger loyalty and lower attrition.
* Newly acquired premium customers require early engagement strategies.
* Contract type strongly influences customer retention.
* Cluster-based retention strategies outperform generalized campaigns.
